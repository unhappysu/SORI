## 2. 측면 회절(보완 사항 8) — 조사 → 영향 확인 → 구현

- **조사**: ISO 9613-2:1996 7.4(식 13, K_met = 1, 경로별 제곱 음압 합), RLS-19 3.5(제외), CNOSSOS-EU 2021 개정(실제 점음원만·최대 2경로·볼록 경로), NoiseModelling(기본 켬), CadnaA(선택). 도로 음원 조각에 쓰는 것은 표준 밖 적용으로 `standard_deviations` 에 기록.
- **1단계 영향 확인**(`tools/lateral_impact.py`, `validation/lateral_diffraction/README.md`): 다른 건물이 측면 경로를 막을 때 A(무시)·B(버림)·C(감싸 돌아감) 비교 → **C 채택**(사용자 결정).
- **구현**(`sori/lateral.py`): 음원점마다 실제 S–R 선 기준 평면 볼록 껍질 → 좌·우 사슬(비스듬한 입사·회전·ㄱ자 건물 그대로), 막는 건물 감싸기 최대 6번, 방음벽 끝도 포함, 지형만으로 막히면 없음, 차폐 없을 때 값 상한(ISO/TR 17534-3 5.6). 성분 `LrT_lateral`. 모델 파일에 건물 외곽선 `bxy`·`bptr`, 방음벽 묶음 `bars_gid`.
- 검증: 수직·비스듬·회전 건물 수계산(1e-9), 막는 건물, 방음벽 끝, 끄면 불변, 시제품 대조 0.3 dB(`tests/test_lateral.py`·`test_lateral_proto.py`).

## 5. 화면(앱)

- **홈 개편**(11-14): 작업 단추 셋 — `데이터 입력` / `입력 지도 확인`(흰 바탕에 수치지도 건물·도로·등고선과 계산 범위만, 소음 없음, 건물·도로 클릭 → 수치지도 속성) / `지도 확인 · 계산`(계산 실행 창 + 격자 지도, 건물 클릭 → 3D 파사드 나란히). **입력 → 계산 → 결과 단계 줄 삭제**.
- **격자 지도 크기**(11-14): ‘해상도가 떨어졌다’는 보고 → 계산 격자(2.5 m)·그리기 dpi 는 그대로이고, 도구 줄이 높아지고(32 → 53 px) 아래 계산·결과 표 창이 지도 확인마다 펴져 지도 창 높이가 660 → 573 px(지도 1.06 → 1.00 px/m, 범위가 세로로 길어 높이가 지도 크기를 정함). 결과가 있으면 아래 창을 펴지 않고, 한 창 보기도 지도만 크게(A3 틀은 저장 때만) → 1600 × 950 창에서 1.41 px/m. 남은 제안: 도구 줄 높이 줄이기, `DISPLAY_STEP` 1.25 m(2.5 m 격자 등음선 보간).
- **11-14 남은 정리**: 도구 줄 여백 줄임(높이 53 → 41 px), 등음선 표시 보간 간격 `DISPLAY_STEP` 2.5 → 1.25 m(2.5 m 격자도 2배 보간, 계산값 불변), 웹 앱 교통량 저장이 `basis`·방향별 비율·속도·M 을 지우던 문제 고침, 지도 정보란에 방향별 속도(다른 도로만) 표기.
- **앱 색표·건물 번호**(11-14 오후): 사용자 "색이 너무 많음, 색을 줄여줘" → 앱 화면(격자·3D 파사드·앱에서 만드는 3D 뷰어·앱에서 저장하는 그림)은 7색 단순 색표(≤50, 50–55 … 70–75, >75 dB, 노랑→빨강 한 계열, `maps_hq.set_palette("simple")` 를 `sori_qt.main` 에서). CLI 보고서 그림은 DIN 11색 그대로(보고서 수정 금지). 사용자 "격자 지도는 빨간 표시만이라 가독성 없음" → 건물을 누르면 격자 지도에도 3D 와 같은 건물 번호(대상 빨간 상자·주변 흰 상자, `plots.bid_label_points` 공통)와 3D 범위 점선 원. 격자 지도는 화면에서 겹치는 주변 번호를 빼고 확대·이동하면 다시 배치. 사용자가 본 앱은 08:21 빌드라 3D 번호가 없었음 → 다시 빌드.
- **앱 3D 파사드**(11-14): 지붕 위 건물 번호(대상 = 빨간 상자, 주변 가까운 30개 = 흰 상자), 3D 창 도구 줄 `소음도 숫자`(기본 켬, 대상 건물 보이는 벽마다 층별 dB 한 열)·`주변 투명`(주변 건물 윤곽선만). 같은 건물을 다시 그리면 돌려 본 시점 유지. `plots.draw_facade_3d` 새 인자는 기본값이면 보고서 그림 불변.
- **3D 뷰어**: 기준 초과 단추·색·문구 삭제(11-13), 뷰어 파일에 판 표시를 넣고 예전 판 파일은 열 때 자동으로 다시 만듦(11-14). 전농사거리 `output`·`output_2026-11-13_측면회절` 뷰어 새로 만듦.
