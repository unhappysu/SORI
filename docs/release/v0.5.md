> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.4.2 이후 앱 화면 기능 추가(판 번호 규칙 README 9절 — 둘째 자리). **계산 결과는 바뀌지 않음**. CLI 보고서 그림도 그대로.

## 격자 지도(앱 화면)

| 날짜 | 내용 |
|---|---|
| 11-14 | 등음선 dB 숫자: 선을 끊지 않는 흰 테두리 글자. 건물·간선 노면 위, 이미 놓인 숫자와 가까운 것, 같은 값이 5개를 넘는 것은 뺌 |
| 11-14 | 관리기준 기준선: 설정 `plots.limits`(없으면 주간 68 / 야간 58 dB)의 등음선을 굵은 남색 선과 `기준 68` 글자로, 범례 띠 오른쪽에 `기준 68 dB` |
| 11-14 | `보기 ▸ 등음선 숫자·기준선`(기본 켬)으로 끄고 켬. 지도 저장(보고서 틀)에는 넣지 않음 |

## 단면

| 날짜 | 내용 |
|---|---|
| 11-14 | 단면이 지나는 도로 노면(중심선 ± 폭/2)을 지면 위 진한 선으로(골목은 옅게) |
| 11-14 | 간선(차로 수 ≥ `model.main_min_lanes`)은 단면 위에 `▼ 도로명 n차로`, 아래 높이별 값 그래프에 노면 가운데 점선 |
| 11-14 | A·B 글자를 단면 바깥 모서리로 옮김(도로명과 겹치지 않게) |
