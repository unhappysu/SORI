# SORI v0.4 — 단면 지도 개선(간격 고르기)

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.3.1 이후 단면 계산점 간격을 고르는 **기능 추가**가 있어 둘째 자리를 올렸다(판 번호 규칙 README 9절). 같은 설정·같은 단면 선이면 자동 간격의 결과는 v0.3.1 과 같다(격자·벽면·점 수음점 계산 불변).

## 기능 추가

| 날짜 | 내용 |
|---|---|
| 11-14 | 단면 계산점 간격 고르기: 단면 선의 두 번째 점을 찍으면 자동(점 4,000개 안쪽) · 2 m · 1 m · 0.5 m 중에서 고름. 선택지마다 계산점 수(`section.estimate`, 모델 래스터만 읽어 1초 안쪽)와 예상 시간(지난 단면 계산 속도, 처음이면 지난 격자 계산 속도). 전농사거리 290 m 단면: 자동 3 m 2,618점 20초, 1 m 23,293점 213초 |

## 앱 화면(계산 불변)

| 날짜 | 내용 |
|---|---|
| 11-14 | 단면을 나란히 보기 오른쪽 창에(경로 보기와 같은 방식), 왼쪽 격자 지도에는 A–B 선. 건물을 누르면 오른쪽은 3D 로 바뀜. 한 창 보기는 평면 + 단면 |
| 11-14 | 단면 색표를 격자·3D 와 같은 색표로(예전 단면은 `classes(30, 5)` 11색이라 격자 지도와 달랐음), 계산점 사이 보간(격자 지도와 같은 방식, 둘러싼 계산점 범위 안으로 제한)과 5 dB 등음선, 지형·지붕은 0.5 m 단면으로 또렷하게 가림 |
| 11-14 | 단면이 지나는 건물 지붕 위에 건물 번호, 세로 과장 배율 표시(예: 세로 ×1.6) |
| 11-14 | 단면 아래에 지면 위 4 m·1.5 m 높이의 A→B 값 그래프(기준 68/58 dB 선, 회색 띠 = 건물) |
