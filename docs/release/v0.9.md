작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.8.1 이후 기본값 변경(판 번호 규칙 README 9절 — 둘째 자리). **결과 바뀜**: 기본 설정에서 외벽(벽면) 수음점을 두는 건물이 바뀜.
격자 소음지도·점 수음점 값은 그대로.

## 전농사거리(격자 480 × 520 m, 지금 설정의 반경 300 m 와 비교)

| | 격자 범위(새 기본) | 반경 300 m(지금 결과) |
|---|---|---|
| 대상 건물 | 872동 | 965동(실제 계산 957동) |
| 격자 안인데 빠진 건물 | 0 | 27동(모서리) |
| 격자 밖 건물 | 0 | 120동 |
| 벽면 수음점(추정) | 약 20,100 | 22,286 |

지금 `output`(11-15 계산)은 반경 300 m 결과. 새 방식으로 보려면 다시 계산해야 함. 설정 파일의 `radius: 300.0` 은 남아 있지만 `area` 가 기본(grid)이라 쓰이지 않음.

## 바뀌지 않은 것

- 기준 사례(`tests/reference/synthetic`)는 입력에 `area: radius` 를 적어 기준값 그대로.
- 소리를 막고 반사하는 건물은 이전과 같이 모델 전체.
