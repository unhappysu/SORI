# SORI v0.8.1 — DEM zip 읽기, 방음벽 전후 조건 확인

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.8 이후 오류 수정(판 번호 규칙 README 9절 — 셋째 자리). 이미 계산되던 입력의 결과는 바뀌지 않음.

## 문제

전농사거리에서 방음벽을 그리고 `▶ 설치 후 계산·비교` 를 누르면 “`…공개DEM_37705_img_2025.zip` not recognized as being in a
supported file format” 오류로 멈춤(2026-11-15 보고). 원인은 방음벽이 아니라 설정의 지형 DEM 경로가 국토정보플랫폼에서 받은
**zip 파일 그대로**였던 것 — rasterio 는 zip 을 열지 못해 모델 만들기 단계에서 실패. 같은 설정이면 일반 계산도 실패함.
설정은 11-12 15:12 에 저장됐고 그 뒤 계산은 없었음(마지막 결과 `output` 은 11-12 15:04, DEM 없이 등고선만).

## 바뀐 것

| 날짜 | 내용 |
|---|---|
| 11-15 | DEM 경로가 zip 이면 안의 래스터(.img·.tif·.tiff) 하나를 GDAL `/vsizip/` 로 읽음(`inputs.dem_source`). 래스터가 없거나 여러 개면 무엇을 쓸지 알 수 없다는 오류. 전농사거리 zip 은 푼 `37705/37705.img` 와 같은 값 |
| 11-15 | 데이터 입력 ▸ 준비할 파일: 지형 DEM 을 미리 열어 보고, 읽을 수 없으면 ✗ 와 이유(계산 중간에 실패하지 않게) |
| 11-15 | 방음벽 `▶ 설치 후 계산·비교`: 설치 전 결과(run_info.json 의 계산 설정)와 지금 설정의 DEM 이 다르면 “차이에 지형 차이가 섞임” 확인 창(기본 취소) |
| 11-15 | 차이 비교(`compare.mismatch`): 전파 방법에 더해 지형 조건(DEM 사용 여부)이 다르면 경고 — `run_conditions.json` 의 diff.warning, 앱 전후 차이 속성 창 ‘⚠ 조건 다름’ |

## 사용자 프로젝트에 대해

전농사거리 현황 결과(`output`)는 DEM 없이 계산됐고, 지금 설정은 DEM 을 씀. 방음벽 전후를 비교하려면 먼저 현황을 지금 설정으로
다시 계산하거나, DEM 을 쓰지 않으려면 설정에서 지형 DEM 칸을 비움. 이번 판은 어느 쪽인지 묻는 창을 띄우기만 함.
