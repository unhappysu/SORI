# SORI v0.7.1 — 데이터 입력 화면 다듬기

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.7 이후 화면 다듬기(판 번호 규칙 README 9절 — 셋째 자리). **계산 결과·설정 파일·CSV 형식은 바뀌지 않음**. 홈 ▸ 데이터 입력의 설정값·교통량·차로 수 탭이 읽기 어렵다는 지적에 따라 글을 줄이고 모양을 고침.

## 공통

| 날짜 | 내용 |
|---|---|
| 11-15 | 탭: 밑줄형(고른 탭 빨간 밑줄). 탭 머리는 파일 이름(굵게)·폴더 한 줄 + 회색 설명 한 줄 — 전체 경로와 긴 설명은 풍선 도움말로 |
| 11-15 | 저장 단추는 남색으로 강조, 표 머리글은 두 줄(이름 / 단위), 줄 높이 28 px |

## 설정값

| 날짜 | 내용 |
|---|---|
| 11-15 | 네 묶음 → 카드 여섯(프로젝트·입력 파일·점 수음점·모델 / 격자·건물 벽면·전파·반사), 빈 공간 없이 두 열로 쌓음 |
| 11-15 | 칸 이름을 짧게(단위는 칸 오른쪽 회색 글), 숫자 칸은 좁게. 긴 설명은 이름·칸의 풍선 도움말 |
| 11-15 | 수치지도 폴더 `필수`·교통량 CSV `권장` 표시, 선택 목록 한글화(차도 면 지형·골목길·지면 계산법·기본 지역) — 저장되는 값은 그대로 |
| 11-15 | ‘지도에서 중심 찍기·범위 보기’ 단추를 격자 카드 안으로. 값 오류 글은 ‘묶음 ▸ 이름’ 으로 |

## 교통량

| 날짜 | 내용 |
|---|---|
| 11-15 | 숫자 오른쪽 맞춤, LW′(자동 계산)은 굵은 남색, 긴 UFID 는 가운데를 줄여 끝자리가 보이게(풍선 도움말에 전체) |
| 11-15 | 값이 하나도 없는 열(방향별 속도·노면·종단경사·정방향 비율·방향 근거)은 숨김 — `모든 열 보기` 로 보임. 숨긴 열도 저장 때 그대로 보존 |

## 차로 수

| 날짜 | 내용 |
|---|---|
| 11-15 | 도로명을 맨 앞에, UFID 는 끝자리, 줄 번호 없앰. 고칠 수 있는 칸 = 흰색, 수치지도 값 = 회색, 계산 결과 = 파랑 |
| 11-15 | ‘적용’ 을 한글로(확인값 / 지도 반씩 / 지도 반씩(올림) / 일방 … + 정방향+역방향 차로 수). 도로 수·확인값 수는 거르기 줄 오른쪽에 |
