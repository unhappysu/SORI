# SORI v0.7.2 — 방음벽 지우기

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.7.1 이후 화면 수정(판 번호 규칙 README 9절 — 셋째 자리). **계산 결과·barriers.csv 형식은 바뀌지 않음**.

## 문제

방음벽이 지워지지 않는다는 보고(2026-11-15). 이전 `선택한 방음벽 지우기` 는 표에서 행을 먼저 골라야만 동작했고,
고르지 않고 누르면 아무 안내 없이 아무 일도 하지 않았음. 지도에 그려진 방음벽 선은 눌러도 고를 수 없었음(격자점 값이 나옴).
방음벽을 넣어 계산한 결과(`…_방음벽` 폴더)를 보고 있으면, 목록에서 지워도 소음지도는 그대로라 지워지지 않은 것처럼 보일 수 있음.

## 바뀐 것

| 날짜 | 내용 |
|---|---|
| 11-15 | 방음벽 표 행마다 ✕ 단추 — 행을 고르지 않아도 그 방음벽을 지움 |
| 11-15 | 지도에서 방음벽 선(화면 7 px 안)을 누르면 그 방음벽을 고름(노란 선, 아래 방음벽 탭이 펴짐) → `지우기` 또는 Delete(⌫) |
| 11-15 | `지우기`: 고른 것이 없고 방음벽이 하나뿐이면 그 하나를 지움. 여러 개인데 고른 것이 없으면 상태 줄에 고르는 방법 안내 |
| 11-15 | `모두 지우기`, `되돌리기`(지운 순서대로 여러 번). 지우기·되돌리기는 바로 barriers.csv 에 저장 |
| 11-15 | 방음벽을 넣어 계산한 결과를 보고 있을 때 지우면 “지금 소음지도는 바뀌지 않음” 을 상태 줄에 알림 |
| 11-15 | 그리는 중 `그리기 취소` 단추·Esc — 찍은 꼭짓점을 버리고 방음벽을 만들지 않음 |
