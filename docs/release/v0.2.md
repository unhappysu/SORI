# SORI v0.2 — 도로교통소음 예측·소음지도

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.1(2026-11-04) 이후 **계산 결과가 바뀌는 기본값 변경**과 계산 방법 추가가 있어 판을 올렸다(2026-11-10). v0.1 로 계산한 결과와 v0.2 결과는 같은 설정으로도 다를 수 있다. 결과 폴더의 `run_info.json` 의 `software` 로 어느 판인지 확인한다.

※ 이 문서는 판 번호 v0.2 의 변경 기록이다. 태그(`v0.2`)·배포 파일(Release 초안)은 아직 만들지 않았다.

## 계산 결과가 바뀌는 변경

| 날짜 | 내용 | 설정 · 이전 동작 |
|---|---|---|
| 11-05 | RLS-90(1990) 계산 방법 추가 — 음원·전파 모두 RLS-90 (SoundPLAN RLS-90 비교용) | `propagation_method: rls90`, `reflection.D_E` |
| 11-06 | 차도 면 지형 보정 기본값: 차도 안 지형을 도로중심선 종단 고도로 평탄화 | `model.road_surface: flatten`(기본) / 이전 `dtm` |
| 11-06 | 교통량 빈칸(M·p)을 계산 방법별 독일 기준표로: RLS-19 표 2 / RLS-90 표 3. 표로 채운 항목은 `traffic_used.csv` 의 `std_filled`·`traffic_std` | 국내 교통 특성과 다를 수 있음 |
| 11-08 | 교통량 자료 없는 골목길(수치지도 1차로)을 음원에서 제외 | `model.minor_roads: exclude`(기본) / 이전 `include` |
| 11-13 | 측면 회절(ISO 9613-2 식 13) 기본 켬 — 건물·방음벽에 막힌 직접음에 좌우 측면 경로. ISO 방법만(RLS-19·RLS-90 은 적용 안 함). 차폐된 뒤편 값이 오름(전농사거리 격자 중앙 +0.40, 55 dB 이하 중앙 +1.56, 도로변 +0.01 dB), 계산 시간 약 +26 %. 이전 판 모델 파일(외곽선 없음)은 경고 후 측면 회절 없이 계산 — build 다시 | `propagation.lateral.enabled: true`(기본) / 이전 `false` |

11-13 보완 사항(방음벽·전후 차이·경로 보기·반사 4–6차·건물별 표·용도지역·측정 − 계산·1.5 m·층별 격자·빠른 미리보기 등)은 기본 설정 결과를 바꾸지 않는다(두 매뉴얼 참고). 기준 사례 기준값은 측면 회절 기본 켬으로 다시 만듦(격자 LrT 평균 +0.53·최대 +6.6 dB, 벽면 평균 +0.42·최대 +2.3 dB, 직접 성분 불변).

11-14: 방음벽 반사 종류(`type`: 반사형 / 반사 저감형 3 dB / 강한 반사 저감형 5 dB / 반사 없음, RLS-90 −4·−8 dB, `refl_loss` 직접 지정), 점 수음점 도로별 기여 `point_road_contrib.csv`, 방음벽 높이별 비교(앱 `높이별 비교…`, `…_방음벽_높이비교.csv`)(모두 계산값 불변). ISO 기상 보정 `propagation.cmet_C0`(기본 0 = 결과 불변). 경로 보기는 경로선을 소음지도 위가 아니라 오른쪽 창에 흰 바탕 확대 그림으로(노랑 = 직접음, 빨강 = 반사음), 점 수음점을 누르면 그 위치·높이로(화면만, 계산 불변). 격자 지도 화면: 결과가 있으면 아래 계산·결과 표 창을 펴지 않고, 한 창 보기도 지도만 크게(A3 보고서 틀은 지도 저장 때만) — 지도가 약 1.4배 크게 보임(화면만). 앱 3D 파사드: 건물 번호(대상 빨강), 벽면 소음도 숫자(기본 켬), 주변 건물 투명(화면만). 등음선 표시 보간 1.25 m, 지도 정보란 방향별 속도 표기, 웹 앱 교통량 저장이 basis·방향별 값을 보존, 앱 도구 줄 높이 줄임(모두 계산 불변). 앱 화면 색표를 7색(노랑→빨강)으로 줄임(보고서 그림 DIN 11색 그대로), 건물을 누르면 격자 지도에도 건물 번호.

## 입력

- 방향별 속도 `v_pkw_fwd`·`v_lkw_fwd`·`v_pkw_bwd`·`v_lkw_bwd`(디지타이즈 방향 / 반대, UFID 행만, 빈칸 = 공통 속도라 입력이 없으면 결과 불변) — 11-11. SoundPLAN 비교 모델처럼 방향마다 속도가 다를 때. 앱 교통량 표·SoundPLAN 내보내기(`vP_fwd` 등)에도 반영

- 차로마다 음원선 `model.source_lines: lane`(차로 중앙, 그 방향 교통량을 차로 수로 나눔, 중심선 대칭 배치 — 기본 `direction` 이라 결과 불변) — 11-11. SoundPLAN 차로별 음원선 비교용

## 앱 화면

- 홈 화면(프로젝트 열기·최근 프로젝트·작업 선택), 입력값 설정 화면(설정값·교통량 표·차로 수 탭) — 11-05
- 격자 소음지도와 3D 파사드 나란히 보기(기본 켬) — 11-05, 홈 화면 작업이 이 선택을 끄지 않게 — 11-10
- 격자 지도 위 벽면 값 띠(층별 최댓값, 격자와 같은 색 등급) — 11-10
- **오류 수정**: 도구 줄 '격자+파사드 나란히'·'단면 선 긋기' 단추를 누르면 함수 인자 오류(TypeError)로 동작하지 않던 것(단추 모양만 바뀌고 오른쪽 3D 창이 켜지지 않음, v0.1 부터) — 11-11
- 나란히 보기에서 왼쪽 격자 지도는 지도만 크게(정보란 없이, 범례는 지도 안), 한 창 보기·지도 저장은 보고서 틀 그대로 — 11-11
- Cmd/Ctrl+S 를 화면별 저장으로(입력값 화면 = 설정 파일, 지도 화면 = 지도 그림) — 11-05

## 기술 검토 반영(2026-11-11, 계산 불변)

- `run_info.json`: 재현용 `environment`(git 커밋·수정 여부, 소스 해시, Python·운영체제, 패키지 판)·`config_resolved`, 표준 원문과 다른 설정 목록 `standard_deviations`, 결합 방법 주의 `hybrid_note`. `D_refl_note` 를 원문 대조 결과로 고침(RLS-19: D_refl + 1·2차가 표준 절차 — TEST-20 K2, RLS-90: + 1차 — 4.6. 기본 3차는 겹침)
- 앱 요약 창에 '표준과 다른 설정' 줄
- 문서: 결합 방법이 RLS-19 와 같은 범위(근거리)와 먼 거리 차이(+4 ~ +8 dB), 국내 「소음지도의 작성방법」 별표 2 대조표(TECHNICAL_NOTES 5b), 시험의 입증 범위, SoundPLAN 비교를 가정 기반으로 다시 씀
- 기본값(반사 3차 + D_refl, 격자 4 m 등)은 바꾸지 않음
