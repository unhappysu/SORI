# SORI v0.2 — 도로교통소음 예측·소음지도

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.1(2026-11-04) 이후 **계산 결과가 바뀌는 기본값 변경**과 계산 방법 추가가 있어 판을 올렸다(2026-11-10). v0.1 로 계산한 결과와 v0.2 결과는 같은 설정으로도 다를 수 있다. 결과 폴더의 `run_info.json` 의 `software` 로 어느 판인지 확인한다.

※ 이 문서는 판 번호 v0.2 의 변경 기록이다. 태그(`v0.2`)·배포 파일(Release 초안)은 아직 만들지 않았다.

## 계산 결과가 바뀌는 변경

| 날짜 | 내용 | 설정 · 이전 동작 |
|---|---|---|
| 11-05 | RLS-90(1990) 계산 방법 추가 — 음원·전파 모두 RLS-90 (SoundPLAN RLS-90 비교용) | `propagation_method: rls90`, `reflection.D_E` |
| 11-06 | 차도 면 지형 보정 기본값: 차도 안 지형을 도로중심선 종단 고도로 평탄화 | `model.road_surface: flatten`(기본) / 이전 `dtm` |
| 11-06 | 교통량 빈칸(M·p)을 계산 방법별 독일 기준표로: RLS-19 표 2 / RLS-90 표 3. 표로 채운 항목은 `traffic_used.csv` 의 `std_filled`·`traffic_std` | 국내 교통 특성과 다를 수 있음 |
| 11-08 | 교통량 자료 없는 골목길(수치지도 1차로)을 음원에서 제외 | `model.minor_roads: exclude`(기본) / 이전 `include` |

## 앱 화면

- 홈 화면(프로젝트 열기·최근 프로젝트·작업 선택), 입력값 설정 화면(설정값·교통량 표·차로 수 탭) — 11-05
- 격자 소음지도와 3D 파사드 나란히 보기(기본 켬) — 11-05, 홈 화면 작업이 이 선택을 끄지 않게 — 11-10
- 격자 지도 위 벽면 값 띠(층별 최댓값, 격자와 같은 색 등급) — 11-10
- Cmd/Ctrl+S 를 화면별 저장으로(입력값 화면 = 설정 파일, 지도 화면 = 지도 그림) — 11-05
