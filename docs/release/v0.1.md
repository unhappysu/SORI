# SORI v0.1 — 도로교통소음 예측·소음지도 (첫 배포)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

SORI(Simulation of Outdoor Road-noise Impact)는 RLS-19 음원 모델과 ISO 9613-2(또는 RLS-19) 전파 계산으로 도로교통소음 격자·건물 벽면·단면 소음지도를 만드는 프로그램입니다. 이 배포판은 Python 설치 없이 더블클릭으로 실행하는 데스크톱 앱입니다.

## 받는 파일

| 파일 | 대상 | 실행 |
|---|---|---|
| `SORI-v0.1-macos-arm64.zip` | Apple Silicon(M1 이후) Mac | 압축을 풀고 `SORI.app` 더블클릭 |
| `SORI-v0.1-windows-x64.zip` | Windows 10/11 64비트 | 압축을 **폴더째** 풀고 `SORI` 폴더 안 `SORI.exe` 더블클릭 |
| `SHA256SUMS.txt` | 받은 파일 무결성 확인용 해시 | — |

Intel Mac 용은 이번 배포에 없습니다.

## 처음 실행할 때 (서명하지 않은 앱)

- **macOS**: "확인되지 않은 개발자" 경고가 나오면 **시스템 설정 → 개인정보 보호 및 보안** 아래쪽 SORI 항목의 **그래도 열기** → 다시 열 때 **열기**.
- **Windows**: "Windows의 PC 보호" 창이 나오면 **추가 정보 → 실행**.

## 주요 기능

- 수치지형도 v2.0(SHP)·교통량 CSV·설정 파일(config.yaml)로 격자·건물 벽면(층별)·점 수음점 계산(주간 LrT·야간 LrN)
- 전파 계산 방법 선택: ISO 9613-2(기본) / RLS-19, 반사 기본 3차
- 화면에서 결과 보기: 보고서 수준 격자 소음지도, 건물 클릭 → 3D 파사드 소음지도, 두 점 클릭 → 단면(수직) 소음지도, 지도 PNG·PDF 저장
- 자가 점검: 좌표 변환과 내장 기준 사례 계산을 기준값과 비교
- 예제(가상 교차로, 실제 지역 아님) 내장

## 확인한 것과 확인하지 않은 것

| 항목 | 상태 |
|---|---|
| macOS(Apple Silicon) | 개발용 맥(macOS 27)에서 빌드·실행·화면 확인, GitHub Actions macOS 러너에서 빌드·자가 점검 통과 |
| Windows | GitHub Actions Windows 러너(Windows Server 2025, x64)에서 빌드하고 `SORI.exe` 자가 점검·예제 계산을 **화면 없이** 실행해 통과. **실제 Windows PC 에서 화면(GUI)·보안 경고 절차는 확인하지 않음** |
| 계산 검증 | pytest(식 단위 재계산, 해석해, 차폐·반사 수계산, 기준 사례 회귀, 좌표 변환, RLS-19 시험과제 TEST-20 대조, 화면 동작). 앱 자가 점검 기준 사례 최대 차이 5e-11 dB |
| 상용 프로그램(SoundPLAN 등) 비교 | 하지 않음 |

## 알려진 제한

- 앱 크기가 큼(macOS 약 610 MB, 압축 전) — 지리 정보 라이브러리(GDAL·PROJ)와 Qt 포함
- 처음 계산할 때 계산 코드 컴파일로 1분 정도 더 걸림
- 반사 3차 기본값에서는 큰 지역 계산이 오래 걸림(전농사거리 약 21분, Apple Silicon 맥북)
- 보고서 지도 정보란: 교통량 설명이 길면 주의 문구가 아래 고지와 조금 겹침
- 단면 지도: 음원(노면 위 0.5 m) 바로 위 낮은 점은 근거리라 값이 매우 크게 나올 수 있음
