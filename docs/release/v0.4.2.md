# SORI v0.4.2 — 3D 뷰어 다듬기

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.4.1 이후 **계산 결과가 바뀌지 않는** 3D 뷰어(`noise3d.html`, three.js) 화면 다듬기(판 번호 규칙 README 9절 — 셋째 자리). 지도·화면 품질 개선 1차의 마지막 항목.

## 3D 뷰어(계산 불변, 뷰어 판 3)

| 날짜 | 내용 |
|---|---|
| 11-14 | 벽면 방향별 명암: 벽면 색은 조명을 받지 않는 재질이라 모든 벽이 같은 밝기로 납작해 보였음 → 장면의 해 방향을 향한 정도로 밝기 0.80–1.0(`fac.s`, 등급 색을 헷갈리지 않게 약하게) |
| 11-14 | 건물 윤곽선(모서리가 25° 넘게 꺾이는 곳, `EdgesGeometry`): 블록 형태가 또렷하게. 주변 건물 숨기기 단추를 누르면 윤곽선도 함께 숨김 |
| 11-14 | 뷰어 판 표시 2 → 3: 앱에서 예전 판 `noise3d.html` 을 열면 묻지 않고 다시 만듦(계산 결과는 그대로) |

전농사거리로 만든 예전·새 뷰어를 헤드리스 Chrome 으로 띄워 비교(스크립트 오류 없음).
