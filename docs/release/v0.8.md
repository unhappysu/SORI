# SORI v0.8 — 소음 관리기준 관련 기능 삭제

작성: 서울시립대학교 환경공학부 전현수(2022890065)

> ※ 본 소프트웨어와 문서는 Claude(Anthropic의 AI)를 활용하여 제작하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

v0.7.2 이후 기능 삭제(판 번호 규칙 README 9절 — 둘째 자리: 출력 파일·설정 항목이 바뀜). **계산 결과(격자·벽면·점 수음점 값)는 바뀌지 않음**.

## 이유

2026-11-15 사용자 결정: 소음 기준은 지역·건물마다 다르므로 프로그램이 한 값(가 지역 68/58 dB 등)을 정해 대조하지 않는다. 기준과 관련된 내용은 모두 뺌.

## 지운 것

| 곳 | 내용 |
|---|---|
| 앱 격자 지도 | 68/58 dB 남색 기준선과 선 위 "기준 68" 글자, 범례 띠의 기준 칸. 메뉴 `등음선 숫자·기준선` → `등음선 숫자`(dB 숫자만) |
| 앱 단면 | 아래 높이별 값 그래프의 68/58 dB 빨간 점선 |
| 앱 건물별 값 | 기준을 넘는 건물의 자주색 테두리 |
| 앱 건물별 탭 | 표의 지역·기준_주·기준_야·초과_주·초과_야·초과 열, `기준 초과 건물만` 체크, 머리 줄의 초과 건물 수·기준 출처 |
| 앱 속성 창 | 계산 결과 요약의 "기준 초과 건물", 건물 클릭 때의 "기준 … dB 초과 n점" |
| 앱 데이터 입력 | 설정값의 용도지역 다각형·이름 열·기본 지역 칸 |
| 보고서 지도(CLI) | 기준 초과 지도 `HQ_exceed_{LrT,LrN}_h*m`(`maps_hq.exceed_map`)를 더는 만들지 않음 |
| 웹 화면(app.py) | 그림 목록의 `HQ_exceed_*` |
| 코드 | `summary.ZONE_LIMITS·zone_code·building_zones`, `maps_hq.DEFAULT_LIMITS·LIMIT_COLOR·EXC_*`, `draw_grid_compact(limit=)` |
| 설정 | `input.zones`, `plots.limits` 기본값. 이전 설정 파일에 있으면 경고만 하고 무시(오류 아님). 예제 `examples/jeonnong/config.yaml` 의 `plots.limits` 줄 삭제 |

## 그대로 둔 것

- 이미 만든 결과 폴더의 `HQ_exceed_*` 그림, 결과보고서·보고서 그림(수정 금지 방침), 현장측정 문서(`field_survey`, `field_measurement`)의 측정 기준·판정 글.
- 색 등급(5 dB 구간)은 기준과 무관한 등급으로 그대로.
- 전후 차이의 "기준(설치 전) 결과"는 관리기준이 아니라 비교 대상 폴더라 그대로.
