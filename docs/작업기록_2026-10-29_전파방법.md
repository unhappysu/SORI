## 6. 근거 미확인 항목

- ISO 그림 3 h_m = F/d 의 d 가 수평거리인지(코드는 두 방법 모두 F/s_gr).
- RLS 3.6 h_R(벽면 높이로 해석), a_R(수평 거리로 해석), 다중 회절 A = B 일 때 C 를 더할 쪽(A 로 해석).
- ISO 대안법 D_Ω 와 차폐 D_z(C2 = 20) 의 중복 여부.
- D_refl(식 9)과 허상음원 반사(최대 3차)의 함께 적용(사용자 결정으로 적용, 이중 계상 가능성 기록).
- 다이어그램 III 식의 적분 변수(dφ 표기, 단위 길이 적분으로 해석).
- ISO 7.3.2 대안법의 적용 조건(다공성 지면)은 포장 지면에서 미충족 — 기본은 일반법.
