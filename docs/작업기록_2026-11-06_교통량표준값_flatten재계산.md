## 1. 교통량 자료가 없을 때의 표준값

| 계산 방법 | 빈칸 M·p 를 채우는 표 | 비고 |
|---|---|---|
| `iso9613_2`, `rls19` (음원 RLS-19) | RLS-19 표 2 (`rls19.TAB2`) | 이전과 같음 — 결과값 불변 |
| `rls90` | RLS-90 표 3 (`rls90.TAB3`, 새로 추가) | 이전에는 RLS-19 표 2 계수와 p1 + p2 를 썼음 |

- RLS-90 표 3 은 원문 PDF(`02_기준원문_참고자료/RLS90-opt in German.pdf`) 12쪽에서 대조: 주간 M = 0,06·DTV(4개 도로유형 모두), 야간 0,014 / 0,011 / 0,008 / 0,011·DTV, p 주간 25 / 20 / 20 / 10 %, 야간 45 / 20 / 10 / 3 %.
- RLS-90 p 우선순위: 입력 `p_day·p_night` → 입력 `p1 + p2` → 표 3. `p_day·p_night` 열이 `TRAFFIC_COLS` 에 없어 교통량 파일에서 읽히지 않던 문제를 함께 고침.
- 독일 기준 명시 위치: `traffic_used.csv` 의 `std_filled`·`traffic_std` 열, `build_info.json` 의 `traffic_defaults`, build 로그 경고, 지도 정보란·3D 뷰어 문구, 앱 교통량 표 안내, README 4.1절 ※, TECHNICAL_NOTES 5a-15, User's·Technical Manual 정식본, 결과보고서 6.2·6.4·7장.
- 차로수별 DTV(`fallback_dtv_by_lanes`)는 두 기준에 없는 SORI 가정값으로 그대로 두고, 표준값과 구분해 적음.
- 시험: `tests/test_rls90.py` 에 5개 추가(표 3 원문값, 4개 도로유형 보충, RLS-19·ISO 불변, p 우선순위, p 열 읽기). 전체 308 통과 + 1 xfail.
