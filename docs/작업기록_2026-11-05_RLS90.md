# 작업기록 2026-11-05 — RLS-90 계산 방법 추가

※ Claude(Anthropic의 AI)를 활용하여 작성하였음.

## 1. 배경

- 학회 참가 주제 "Python을 활용한 AI기반 도로교통소음 예측 사용 프로그램 제작". 확장요약문(`2026 추계 확장요약문.pdf`)은 RLS-90 구현, SoundPLAN 9.1 RLS-90 결과와 비교로 되어 있음.
- SORI 는 RLS-19 음원 + (ISO 9613-2 | RLS-19) 전파만 있었음 → SoundPLAN RLS-90 과 같은 기준으로 비교할 수 없음. 사용자 결정: SORI 에 RLS-90 추가.
- 받은 SoundPLAN 결과: 사가정로 측정점 주변 좁은 구역의 LrD 지도 그림(숫자 결과 아님).

## 2. 원문

`02_기준원문_참고자료/RLS90-opt in German.pdf`(Ausgabe 1990, 21쪽)에서 쓴 식: (1)(2) 표 2 K, (3) 두 바깥 차로, (6)~(9) 표 4 음원, (19)~(27) Teilstück-Verfahren, 4.6·표 7 반사.

## 4. 검증

- `tests/test_rls90.py` 47건 통과: Bild 22 예(차로당 L_m,E 67,7 / 63,0 dB(A)), 식 (8)·표 4·식 (9)·표 2 경계, 평지·단일/이중 회절·1차 반사를 원문 형식으로 수계산해 1e-9 dB 일치, 합성 사례 build → run 전 과정.
- `tests/test_method_verification.py::test_terms_csv_closure` 에 rls90 추가(경로별 L_day 합 = LrT_direct·LrT_refl1, K 포함).
- 합성 기준 사례 격자 LrT(rls90 − rls19): 평균 +0.30, −2.22 ~ +3.85 dB. K = 0/1/2/3 dB 격자점 1070/254/166/100.
- 한계: 모두 같은 저자의 수계산 대조. RLS-90 공식 시험과제나 SoundPLAN 숫자 결과와 대조한 것은 아님.

## 5. SoundPLAN 비교 때 맞출 것

1. 반사 차수(RLS-90 4.6 은 1차) — SORI 기본 3 → 비교 설정에서 1 로.
2. 반사 손실 D_E(−1 매끈한 외벽).
3. 교차로 K: SoundPLAN 에 신호교차로를 넣었는지, 같은 교차점인지.
4. 노면 D_StrO, 속도, p(> 2,8 t) 정의.
5. 수음점 높이·격자 간격, 건물 높이, 지형(DTM)·차도 면 처리.
6. 숫자 결과(수음점 표, 격자 ASCII/CSV)를 받아야 통계 비교 가능.

## 6. SoundPLAN 비교 준비(같은 날 추가)

- `validation/soundplan/`: RLS-90 비교 설정(반사 1차, D_E −1, 사가정로 측정점 주변 240 × 160 m 격자 2.5 m·4 m, 수음점 21개 = 측정점 3 + 횡단 측선 18), 절차 `README.md`. 계산 약 25초. 결과 예: P1 LrT 78.16 / P2 78.87 dB(RLS-90).
- `tools/export_soundplan.py`: SORI 가 쓴 도로(교통량·p·속도·노면·음원선 오프셋·L_m,E)·음원선·건물·신호 교차점·수음점·계산 영역 셰이프파일, 지형 표본, `계산조건.md`(SoundPLAN 에 맞출 설정표) 생성.
- `tools/compare_soundplan.py`: SoundPLAN 수음점 표(.csv/.txt/.xlsx, 이름 또는 좌표로 맞춤)·격자(.asc 또는 x y 값 표) 읽기(구분자·소수 쉼표 자동), 통계(평균 차이·SD·RMSE·MAE·최대·±0.5/1/2/3 dB 비율·r·기울기·Bland–Altman), 그림 4종.
- 시험 `tests/test_soundplan_tools.py` 6건: 가짜 SoundPLAN 파일(독일어판 형식, ESRI ASCII)에 넣은 차이를 되찾는지, 합성 사례 내보내기. 실제 SoundPLAN 파일은 아직 없음.
