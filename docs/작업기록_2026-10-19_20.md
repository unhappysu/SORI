## 1. 실험노트 (날짜별)

### 2026-10-19 ① 기준 조사(1단계) — 국가법령정보센터 원문

- **목적**: 현장 측정 양식에 쓸 측정방법·기준값을 1차 출처로 확인.
- **입력**: law.go.kr 의 「소음·진동공정시험기준」 현행 고시(첨부 전문 zip 3.7 MB, 사용자 승인 후 다운로드), 환경정책기본법 시행령 [별표 1], 소음·진동관리법 시행규칙 [별표 11](둘 다 사이트의 별표 이미지 판독).
- **결과**
  - 공정시험기준 현행본: 국립환경과학원고시 제2026-39호(2026-09-14 일부개정·시행), 총 17종.
  - 적용 방법: ES 03301.1c(환경기준 중 소음측정방법, 2020), ES 03304.1d(도로교통소음관리기준 측정방법, 2024), ES 03300.c(총칙, 2026). 관련 원문 PDF 5개를 `field_survey/references/소음진동공정시험기준_2026-39호/` 에 보관.
  - 소음 환경기준(별표 1, 2025-10-01 개정분)과 도로 교통소음 관리기준(별표 11, 2019-12-31 개정분) 값을 표로 정리 → `field_survey/references/기준조사_1단계_결과.md`.
- **중요한 확인 사항**
  - 법정 평가의 여러 회 평균은 **산술평균**(ES 03301.1c 5.3, ES 03304.1d 7.1.1.2). 작업 지시의 "에너지 평균"과 달라 사용자에게 확인 → **법정 평가 = 산술평균, 시뮬레이션 비교 = 측정시간 가중 에너지평균(자체 설정)** 으로 결정.
  - 배경소음 보정 조항은 두 적용 방법에 없음(보정표는 생활소음 방법 ES 03303.1d 7.2 에만 있음) → 보정하지 않음.
  - 교정 전후 허용 편차, 강우·노면 조건은 원문에 규정 없음 → "미확인"으로 표시하고 사용자 기입 칸으로 둠.
- **확인 못 한 것**: KS C IEC 61672-1(2022)·ISO 1996-2 본문(열람 안 함), 측정점 주변 용도지역.

### 2026-10-19 ② 측정계획서(4-1)

- **결과**: 측정점 후보 9개(R1·R2 도로변, F1·F2 파사드, B1·B2 이면도로·배후지, V1~V3 검증점), 좌표는 빈칸(`field_survey/plan/measurement_points.csv`·`.geojson`). 소음계 2/3/4대 이상 시나리오, 회차 D1 07:30 · D2 11:30 · D3 15:30 · D4 19:30 · N1 22:30 · N2 02:30(4시간 간격 → 환경기준·도로교통 요건 동시 충족), 회차 내 시각표, 1회 10분 측정.
- **오류 분석**
  - Microsoft Word 자동화(AppleScript)로 PDF 변환 시도 → docx XML 요소 순서 오류(tblW·shd·pBdr)와 `updateFields` 확인 창 때문에 Word 가 멈춤. XML 은 고쳤으나(검사 통과) 사용자 요청으로 Word 자동화는 중단.
  - **Pages 로 PDF 변환**하는 방식으로 바꿈. 맑은 고딕은 macOS 시스템 글꼴이 아니라(Word 내장) Pages 가 명조로 바꿈 → PDF 용 docx 만 시스템 글꼴 Apple SD Gothic Neo 로 따로 만듦. docx 원본은 맑은 고딕.

### 2026-10-20 ③ 측정 야장(4-2) · 결과보고서 양식(4-3) · 처리 스크립트(4-4)

- **야장 xlsx**: 측정개요·측정점·소음기록·교통량(5분, 6개 차종, 이륜차 별도)·신호속도·기상·계산 시트. 입력 칸(노랑, 잠금 해제)과 수식 칸(파랑, 잠금) 구분, 시트 보호(암호 없음).
- **수식 검증의 오류 분석**
  - Numbers 로 열어 계산값을 읽으려 했으나 이 파일을 빈 문서로 가져옴 → 원인 미확인, 중단.
  - 임시 폴더에만 설치한 `formulas` 패키지로 시험값을 계산해 손계산과 대조. `COUNTIFS(…,"<>")`·`SUMPRODUCT(ISNUMBER())` 가 기대값과 다르게 계산됨 → 보조 열(유효 1/0, 가중값)과 `SUMIFS` 로 바꿈. `MINIFS`(신규 함수) 는 쓰지 않음.
  - 최종: 빈 야장·시험값 사본 모두 수식 오류 0개, 산술평균 71.0, 에너지평균 71.6/60.4/65.7, 시간당 교통량 1,464 대/h 등 손계산과 일치.
- **인쇄용 야장 PDF**: 처음 판에서 카드 3장/쪽이 넘쳐 빈 쪽 발생 → 2장/쪽으로 조정, 10쪽.
- **보고서 양식**: 결과 자리는 모두 빈칸 또는 "[측정 후 기입]". 산점도 설명에서 근거 없는 "±3 dB 선" 문구 삭제.
- **`process_measurements.py`**: 야장 입력 칸만 읽어 다시 계산(엑셀 수식 결과에 의존하지 않음). 출력 `measured_levels.csv`(point_id, x, y, z, period, Leq, n_samples, valid_flag, traffic_count_ref + 법정 산술평균·정수값·횟수 충족). 반올림은 사사오입(파이썬 `round()` 의 짝수 반올림 사용 안 함). 모델 CSV 가 있으면 `comparison.csv`·`comparison_summary.csv`(평균·표본표준편차·최대 차이).
- **시험 작성 중 오류**: 시간 가중 시험의 손계산을 잘못 적음(20·10⁶ + 10·10⁷ 을 3×10⁷ 로 계산) → 코드가 맞고 시험 기대값이 틀림, 4×10⁶ → 66.02 dB 로 정정.

### 2026-10-20 ④ 점 수음점 입력(소프트웨어)

- **배경**: 측정점과 같은 좌표·높이의 모델 계산값이 필요하나 격자(높이 4 m)·파사드(외벽 앞 5 cm)만 있었음.

- **출력**: `point_result.csv`, `point_levels_for_comparison.csv`(process_measurements.py `--model` 형식).
- **검증**: 격자점과 같은 좌표·높이의 점 수음점이 격자 결과와 일치(가상 경사 지형·건물 1동 시험). 기준선 비교 "같음". README 4.5·5·6절, `config_example.yaml` 갱신.

## 3. 결정 사항

1. 법정 평가는 산술평균, 시뮬레이션 비교는 측정시간 가중 에너지평균(자체 설정, 문서에 명시).
2. 배경소음 보정은 하지 않음(적용 방법에 조항 없음). 처리 스크립트에는 TODO 로만 표시.
3. 1회 측정 10분, 회차 시작 4시간 간격(환경기준·도로교통 요건 동시 충족). 회차 간 간격은 자동 확인하지 않고 수동 확인.
4. 교통량은 6개 차종으로 세분 계수, 소프트웨어 차종(Pkw/Lkw1/Lkw2) 대응은 RLS-19 원문 확인 후 결정(미확인).
5. 생성 문서(docx·pdf·xlsx)는 커밋하지 않고 스크립트로 다시 만듦. PDF 는 Pages 로 변환(글꼴 Apple SD Gothic Neo).
6. 소프트웨어 변경은 옵션으로만 추가(점 수음점 경로를 지정하지 않으면 이전과 같음).

## 4. 다시 만드는 방법

```bash
python field_survey/scripts/survey_points.py                 # 측정점 CSV·GeoJSON (좌표 채운 뒤에는 --from-csv)
python field_survey/scripts/build_plan_docx.py --pdf          # 측정계획서
python field_survey/scripts/build_fieldbook_xlsx.py           # 야장 xlsx
python field_survey/scripts/build_fieldbook_print.py --pdf    # 인쇄용 야장
python field_survey/scripts/build_report_docx.py --pdf        # 보고서 양식
python field_survey/scripts/process_measurements.py field_survey/forms/소음측정_야장.xlsx --model output/point_levels_for_comparison.csv
python -m pytest -q tests field_survey/tests
```

`--pdf` 는 macOS Pages 가 필요함. 필요 패키지: python-docx, openpyxl(엑셀 대조 시험은 `formulas` — 기본 환경에 없으면 건너뜀. 임시 폴더 설치 시 numpy 버전 경고가 있어 기본 환경 설치는 하지 않았음).
