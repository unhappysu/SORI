## 2. 방법의 구성(EPA 지침 요약)

**음원(도로)**
- 차종 5가지: 1 경차량(승용 등), 2 중형 중차량, 3 대형 중차량, 4 이륜(4a 원동기장치자전거·4b 오토바이), 5 예비(전기·하이브리드 등).
- 차종마다 **옥타브 대역 63 Hz ~ 8 kHz** 의 구름 소음(타이어–노면) + 추진 소음(엔진 등). 기준 속도 70 km/h, 계수표(대역·차종별)로 계산.
  - 구름: 기준 속도 대비 로그 속도 항 + 보정(노면, 스터드 타이어, 신호교차로·회전교차로 가감속, 기온 — 기준 20 °C, 경차량 약 0.08 dB/°C).
  - 추진: 속도 선형 항 + 보정(노면 흡음, 종단경사 — 차종별·방향별, 최대 ±12 %, 가감속).
- 음원 높이 **0.05 m**(RLS-19 0.5 m 와 다름), 차로마다 음원선이 원칙(방향별·중앙 1개선도 허용).
- 시간대: EU 기본 주간 07–19·저녁 19–23·야간 23–07 시, **L_den**(저녁 +5, 야간 +10 dB 가중)·L_night. 국내 자료(주간 06–22·야간 22–06)와 다름.

**전파(NMPB-2008 기반)**
- 경로마다 **두 기상 조건**을 따로 계산: 균질(곧은 경로)·순풍(아래로 휜 경로). 장기 레벨 = 균질과 순풍 에너지를 순풍 발생 비율 p(방향별 지역 기상 통계)로 가중 합.
- 감쇠 = 기하 확산 + 공기 흡음 + (회절이 없으면) 지면 감쇠 또는 (있으면) 지면 효과를 포함한 회절 감쇠. 기상의 영향은 지면·회절 항에만.
- 지면: 경로 아래 **평균 지면(최소제곱 평면)** 과 G_path, 균질·순풍 식이 다름.
- 회절: 경로차 δ — 균질은 직선, 순풍은 **원호 경로**로 계산. 측면 회절은 **실제 점음원(산업)만**, 최대 2경로(2021 개정).
- 반사: 허상음원, 반사면 흡음계수(대역별), 높이 경사 15° 이내 면만, 측면 경로에는 반사 없음.
- 품질: ISO/TR 17534-4 인증 소프트웨어면 지침 품질 기준 충족(아일랜드 EPA 권고).

## 3. SORI 와 비교

| 요소 | SORI 지금 | CNOSSOS 에 필요한 것 | 작업량 |
|---|---|---|---|
| 음원 | RLS-19 / RLS-90, A 가중 단일값 | 5차종 × 8대역 계수표·보정식, 음원 0.05 m | 중(계수표만 있으면 식은 단순) |
| 교통량 입력 | 주간·야간 M, p1·p2(RLS 차량군) | 차종 1–4 대수, 주간·저녁·야간 3시간대 | 중 — 국내 자료에 저녁 시간대 없음(가정 필요), 12종 → 차종 1–4 변환표 필요 |
| 대역 계산 | ISO 경로는 여러 대역 지원(지금 500 Hz 1대역) | 8대역 전 구간 — 계산 시간 약 2–4배(대역별 감쇠만 늘고 기하는 공통) | 소 |
| 기하 | 연직 단면·볼록 껍질·측면 회절 | 같음 + 평균 지면 평면(최소제곱), 순풍 원호 경로차 | 중 |
| 감쇠식 | ISO 9613-2 / RLS-19 / RLS-90 | NMPB 지면(균질·순풍), Δdif(균질·순풍), 장기 합(p) | 대 — 새 방법 모듈(`propagation_method: cnossos`) |
| 반사 | 차수 0–6, ρ / D_RV / D_E, 방음벽 종류 | 대역별 흡음계수 | 소 |
| 기상 자료 | 없음(C_met C0 만) | 방향별 순풍 발생 비율 p(주·저녁·야), 기온·습도 | 자료 확보가 관건 |
| 지표 | LrT·LrN | L_den·L_night | 소 |
| 검증 | TEST-20(RLS-19), 수계산 | ISO/TR 17534-4 시험 사례(유료) 또는 NoiseModelling 대조 | 중 |

## 4. 국내 관점

- 「소음지도의 작성방법」 별표 2 제3호가 열거한 예측식에 **NMPB** 가 있음. CNOSSOS 전파는 NMPB-2008 기반이라, 지금의 'RLS-19 음원 + ISO 9613-2 전파'(열거 밖 결합)보다 고시와의 관계 설명이 쉬움. 다만 CNOSSOS 음원·계수표는 유럽 차량 기준이고 국내 검증 자료는 확인하지 못함.
- 국내 교통량 자료에 저녁 시간대·차종 1–4 구분이 없어, 쓰려면 시간대 분할·차종 변환 가정이 늘어남.

## 5. 제안(사용자 결정 필요)

1. **원문 확보부터**: EUR-Lex 에서 2015/996(OJ L 168, 2015-07-01)·2021/1226(OJ L 269, 2021-07-28) PDF 와 정오표(2018)를 받아 `02_기준원문_참고자료/원문/` 에 둠(계수표·식 번호 대조용). 가능하면 ISO/TR 17534-4:2020(학교·도서관).
2. 원문을 받으면 단계로 나눠 구현:
   - (가) CNOSSOS 도로 음원(5차종 × 8대역) + 지금 ISO 9613-2 전파(8대역) — 음원 차이부터 확인(설정 하나로 선택).
   - (나) NMPB 전파(균질·순풍, 평균 지면, Δdif, 장기 합)를 `propagation_method: cnossos` 로.
   - (다) L_den·L_night, 방향별 순풍 비율 입력, 검증(시험 사례 또는 NoiseModelling 같은 입력 대조).
3. 시간: (가) 며칠 규모, (나)·(다)는 더 큼. 8대역이라 계산 시간도 늘어남.
