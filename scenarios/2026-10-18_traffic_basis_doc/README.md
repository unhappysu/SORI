## 해석

- 주·야 계수(A)는 DTV 와 무관하게 **야간 +3.3 dB / 주간 −0.45 dB** 를 만든다. 서울 28곳의 편차(야간 0.0149~0.0261)를 고려해도 표 2(0.0100)보다 확실히 크므로, 어떤 DTV 를 쓰든 서울 주·야 계수를 쓰는 것이 타당해 보인다(결정 필요).
- DTV(B)는 기준선 가정값보다 작아 주간 −1.8 dB(파사드 평균), 사가정로 근처 최대 −3.1 dB. 야간은 계수 효과와 상쇄되어 +1.1 dB.
- 남은 불확실성: 차로당 DTV 분위 선택(문서 민감도 −2.2 ~ +1.1 dB), 답십리로·서울시립대로 값(문서에 없음), 차종 비율(표 2 가정). 현장 1시간 계수(문서 7절)로 점검 가능.
