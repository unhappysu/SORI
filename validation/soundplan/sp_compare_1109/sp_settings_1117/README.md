- **도로변은 일치**: SoundPLAN ≥ 75 dB 199점 평균 −0.51, SD 0.82 dB(어느 반사 규칙에서나 비슷).
- **건물 뒤는 불일치**이고 반사 거리 규칙에 크게 좌우된다(같은 점에서 최대 8.9 dB). SoundPLAN 규칙을 문자 그대로 적용하면 가장 낮다. 이날 오전 `matched` 결과로 "건물 뒤 차이가 줄었다"고 본 것은 SoundPLAN 이 쓰지 않는 반사를 더한 근사의 효과였으므로 **철회**.
- 확인할 것: ① SoundPLAN 의 '음원에서 50 m' 판정(분할 구간별인지, 도로 전체 기준인지, 첫 반사면만인지), ② SoundPLAN 격자 보간 해제 재계산(남측 건물 뒤 SoundPLAN 값이 40 m × 20 m 에 걸쳐 62–63 dB 로 평평 — 보간 의심), ③ 건물 외곽선·다중 회절.
- 지형 평활 영향은 작다(평균 0.07, 95 % 0.39 dB).
- `matched`·`r_default` 의 `run.log` 는 같은 폴더에서 계산이 겹쳐 돌았던 때의 기록이라 순서가 섞여 있을 수 있음(결과 파일은 같은 설정의 정상 완료본).
