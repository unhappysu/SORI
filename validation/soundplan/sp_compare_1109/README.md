## 이 비교를 읽는 법 (2026-11-11 검토 반영)

- **가정 기반 비교**다. SoundPLAN 의 실제 설정(노면, 반사 차수·반사 손실, 교통량·화물차 비율, 신호교차로 보정, 다중반사 가산값, 건물 높이, 탐색 반경)을 받지 못했고, 아래 "최종 조건"은 **결과를 본 뒤** 노면과 반사 차수를 바꿔 수음점 차이가 가장 작아진 조건이다. "SoundPLAN 과 일치", "동일 조건 비교"라고 쓰지 않는다. 쓸 수 있는 표현: "SoundPLAN 설정을 가정한 조건에서 도로변 수음점이 ±0.3 dB 안, 격자 전체 RMSE 3.8 dB".
- 표의 **모든 조건을 함께** 보고한다(가장 잘 맞는 조건만 내세우지 않음). 수음점 2곳의 근접(+0.30·−0.01 dB)과 격자 전체(RMSE 3.80 dB, ±2 dB 안 57 %)는 다른 이야기다.
- 계산은 모두 `propagation_method: rls19`(RLS-19 음원 + RLS-19 전파)다. **SORI 기본값인 RLS-19 음원 + ISO 9613-2 전파를 검증한 비교가 아니다.**
- SORI 는 신호교차로 보정 D_K(이 구간 음원 427개, 최대 2.97 dB; 수음점 P1·P2 부근 음원의 에너지 가중 평균은 0.05·0.01 dB)와 다중반사 D_refl(음원 564개; P1·P2 부근 0.13·0.26 dB)을 넣었다. SoundPLAN 모델에 이 둘이 있는지 **미확인**.
- 제외한 점: SoundPLAN 격자 701점 중 149점은 SORI 건물 안이라 값이 없다(`point_result.csv` 의 note "건물 안" — 두 모델의 건물 자료가 다름). 비교는 격자 552점 + 수음점 2곳 = 554점.
- 격자점은 5 m 간격이라 서로 독립이 아니다(공간 상관). n = 554 의 SD·RMSE 는 표본 554개의 정밀도가 아니라 구역별 차이의 크기로 읽는다.

### 현장 측정과의 관계

SoundPLAN 수음점 값(74.09·77.30 dB)도 현장 측정 LAeq(지점1 68.6·지점2 69.1 dB, 2026-10-22)보다 약 5.5·8 dB 높다(좌표가 4.6·9.5 m 다르고 SoundPLAN 교통량은 미확인). 즉 측정보다 높게 나오는 것은 SORI 만의 현상이 아니며, 두 프로그램이 같은 방향으로 어긋난다는 것은 "SoundPLAN 과 가깝다 = 현장 예측이 맞다"가 아님을 뜻한다.

## 차이의 후보 (확인 전)

1. **교통량**: SoundPLAN 의 교통량(대/h)·화물차 비율을 아직 모름. 도로변 점의 일정한 −2.4 dB 는 교통량·화물차 비율 차이로 설명될 수 있는 크기(교통량 1.7 배 ≈ +2.4 dB).
2. **다른 도로**: SoundPLAN 지도에는 사가정로만 있다. SORI 는 전농로·주변 도로도 음원이라 서쪽(전농로 쪽)에서 SORI 가 높고(차이 지도 빨강), 이 영향은 SoundPLAN 에 없다.
3. **차로·음원선**: SoundPLAN 3 + 2차로, 차로마다 음원선. SORI 는 수치지도 차로 수(구간마다 4–6) 양방향 2개선.
4. **건물**: SoundPLAN 격자점 중 149개가 SORI 건물 안(141개)이거나 계산 범위 밖이라 SORI 값이 없다 — 건물 자료(범위·높이)가 다를 수 있음. 건물 뒤 점(SoundPLAN 60–65 dB)은 차이 평균 −5.5, SD 6.1 dB 로 흩어짐이 크다(차폐·반사 조건 차이).
5. **반사 차수·지형·수음점 높이 정의**: SoundPLAN 설정 미확인. SORI 는 반사 1차.
