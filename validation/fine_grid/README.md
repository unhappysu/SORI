# 세분 격자(삼각망 보간) 검토 — 경계를 더 촘촘히 계산하는 적응 격자

※ Claude(Anthropic의 AI)를 활용하여 작성하였음. 2026-11-15.

**목적**: `validation/adaptive_grid` 검토는 가장 촘촘한 간격을 지금과 같은 2.5 m 로 두고 절약만 봤음. 이번에는 반대로 **건물·도로 경계를 2.5 m 보다 촘촘히(0.625 m까지) 계산하면 지금 격자의 오차가 얼마나 줄고 계산점이 얼마나 느는지** 확인.

**방법**: `tools/fine_grid_study.py`(계산 엔진 변경 없음, `sori.run._run` 으로 점만 계산).
- 전농사거리 100 m × 100 m 두 구역을 0.625 m(2.5 m 의 1/4) 간격, 높이 4 m, LrT 로 모두 계산 → 정답. 같은 엔진·같은 설정(반사 3차, 측면 회절은 모델 파일에 외곽선이 없어 끔 — 지금 `output` 격자와 같은 조건).
  - 골목_북동: 왼쪽 아래 (205109.25, 553131.25) — 간선 북쪽의 단독·다세대 골목
  - 아파트_남동: 왼쪽 아래 (205169.25, 552951.25) — 아파트 단지와 빈 땅
- 방식마다 계산했어야 할 점만 정답에서 골라 나머지를 삼각망(Delaunay 1차) 보간, 건물 밖 정답 점에서 오차.
- 적응 규칙: 2.5 m 에서 시작, 칸(네 꼭짓점)이 건물·간선 노면 띠에 닿거나 네 값 범위가 기준(2·1 dB)을 넘으면 칸 안을 반 간격으로, 0.625 m 까지 되풀이.

## 판단

- **지금 2.5 m 격자는 건물 가까이에서 많이 놓침**: 건물 5 m 안 점의 14–15 % 가 1 dB 넘게, 최대 9–11 dB 틀림(벽 모서리 그림자·골목 입구). 건물에서 떨어진 곳은 대부분 0.1 dB 안팎(아파트 단지 빈 땅은 높은 건물 그림자 경계 때문에 최대 4.7 dB).
- **균일하게 1.25 m 로 줄이는 것은 비효율**: 계산 4배에 최대 오차가 거의 그대로(8–10 dB) — 경계는 여전히 칸 사이에 걸림.
- **적응(건물·도로 + 2 dB)이 같은 비용대에서 가장 나음**: 아파트 4.5배로 최대 1.75 dB·1 dB 초과 0.5 %, 골목 7.7배로 95 % 0.25 dB·1 dB 초과 0.3 %(최대 5.4 dB 는 몇 점). + 1 dB 면 두 구역 모두 최대 약 2 dB 이하이나 8–9배.
- 계산점이 건물 밀도에 따라 4.5–8배 늘어남 → 전농사거리 전체(지금 25,719점, 이 컴퓨터에서 점당 약 0.017 초 ≈ 7분)는 약 35–55분 예상. 앱에서는 ‘정밀 격자(경계 세분)’ 같은 선택 사항이 알맞음(기본은 지금 2.5 m).
- 넣는다면 필요한 일: 계산을 단계별로(2.5 → 1.25 → 0.625 m, 단계마다 칸 판단), 결과를 불규칙 점 표(`grid_result.csv` 에 간격 열)로 저장, 지도 그리기를 삼각망 등음선(`tricontourf`)으로, GeoTIFF 는 0.625 m 로 보간해 내보내기, 보고서·3D 뷰어 바닥 그림 갱신.
- 한계: 두 구역(100 m)만 봄. 정답도 0.625 m 격자라 그보다 작은 변화는 모름. 높이 4 m·LrT 만.

## 덧붙임 — SoundPLAN 비교와의 관계(2026-11-15, `sp_sensitivity.py`)

위 검토는 SORI 계산값끼리의 비교(격자 간격·보간 오차)다. SoundPLAN 과의 차이가 격자·위치 문제인지 보려고, 이전 SoundPLAN 비교(`validation/soundplan/sp_compare_1109/sagajeong_only/r3_ref`: 사가정로만 음원·반사 3차·기준 노면, SoundPLAN 격자점 552개에서 SORI 를 점으로 직접 계산 — 보간 없음)의 각 점을 1.25·2.5 m 옮겨 다시 계산했다.

- 차이는 건물 가까이에서 크다(RMSE 4.1 vs 10 m 밖 2.3 dB) — 두 모델의 건물 자료(SoundPLAN 격자점 149개가 SORI 건물 안)·차폐·반사 설정 차이로 보이며, SoundPLAN 설정은 여전히 미확인.
