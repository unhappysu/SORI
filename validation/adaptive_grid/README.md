# 적응 격자(삼각망 보간) 검토 — 보완 사항 2번

※ Claude(Anthropic의 AI)를 활용하여 작성하였음. 2026-11-14.

**목적**: 계산 시간을 줄이려고 격자를 거칠게 계산한 뒤 필요한 곳만 촘촘히 계산하고, 나머지는 삼각망(TIN, Delaunay 1차) 보간으로 채우는 방법이 쓸 만한지 확인.

**방법(모의, 계산 엔진 변경 없음)**: `tools/adaptive_grid_study.py`. 전농사거리 2.5 m 격자 결과(25,719점)를 정답으로 두고, 적응 격자였다면 계산했어야 할 점 수(≈ 계산 시간)와 나머지를 보간했을 때의 오차를 셈. 세분 규칙: 거친 격자(10·20 m)에서 시작해 간격을 반씩 줄이며, 칸의 네 꼭짓점 값 범위가 기준(1·2·3 dB)을 넘거나 칸이 건물·간선 노면 띠에 닿으면 세분. 측면 회절 끔(11-08)·켬(11-13) 두 결과로 확인. 전체 표: `adaptive_grid_study.csv`.

## 판단

- 전농사거리처럼 건물이 빽빽한 곳의 2.5 m 격자는 **거의 모든 칸이 건물이나 도로에 닿아** 세분해야 함(규칙만으로 75 %). 안전한 설정(건물·도로 + 2 dB)으로 줄일 수 있는 계산은 **약 15 %** 이고, 그 대가로 최대 2 dB 안팎의 보간 오차가 생김.
- 건물·도로 규칙을 빼면 계산은 40–60 % 로 줄지만 건물 뒤 그림자 경계·도로 가장자리를 놓쳐 **최대 15–25 dB** 틀림 — 소음지도로 쓸 수 없음.
- **결론: 지금은 구현하지 않음을 권장**(계산 절약이 작고 결과 신뢰도를 떨어뜨림). 계산 시간이 문제면 ‘빠른 미리보기’(격자 간격 2배·반사 1차)를 쓰거나, 넓은 교외 지역(건물이 드문 곳)에서 다시 검토.
- 한계: 모의는 정답 격자(2.5 m)의 부분집합만 고르므로 실제 적응 계산과 같은 점 위치. 벽면 수음점은 대상 아님.
