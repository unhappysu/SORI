※ Claude(Anthropic의 AI)를 활용하여 작성하였음. 2026-11-13.

계산 엔진은 바꾸지 않고, 전농사거리 기존 결과(`03_전농사거리_SORI계산/output`, 2026-11-08 계산, ISO 9613-2 전파·500 Hz·G = 0·반사 3차)를 읽어 **직접음 경로에 측면 회절을 더했을 때 격자 LrT(4 m)가 얼마나 바뀌는지** 대표 점에서 계산했다. 도구 `tools/lateral_impact.py`, 수계산 대조 `tests/test_lateral_proto.py`.

## 계산 규칙(시제품)

- 대상: 연직 단면이 **건물**로 막힌 직접음 경로(지형만으로 막히면 없음 — ISO/TR 17534-3 5.8). 반사 경로에는 넣지 않음(CNOSSOS).
- 경로: 평면에서 S·R 과 직접 경로가 뚫는 건물 꼭짓점의 볼록 껍질(고무줄) → 좌우 최대 2개. 높이는 S→R 직선 보간.
- 감쇠: ISO 9613-2 식 (13) `A = A_div(d) + A_atm(경로 길이) + A_gr(측면 경로 아래, 식 9) + D_z(식 14, K_met = 1, C3 식 15, 상한 20/25 dB)`.
- 합치기: 윗모서리 + 좌 + 우 에너지 합, 차폐 없을 때 값을 넘지 않게(TR 17534-3 5.6).
- 다른 건물이 측면 경로를 막을 때 세 변형:
  - **A** CNOSSOS 식 — 무시(지면 항에만). 큰 쪽 추정.
  - **B** 그 경로를 버림. 작은 쪽 추정.
  - **C** 막는 건물을 그 쪽 껍질에 더해 다시 돌아감(최대 6번, NoiseModelling 의 옆 껍질 탐색과 비슷한 생각).
- 확인: 직접음 합이 격자 결과 `LrT_direct` 와 최대 9e-7 dB(같은 계산을 다시 한 것이 맞음). 수계산 대조 3개 통과.

## 읽는 법

- **도로변(65 dB 이상)은 거의 바뀌지 않음**(0.1 dB 안). 현장 측정점(도로변)의 모델 과대 계산(+5.6 ~ +8.5 dB)은 측면 회절로 설명되지 않음.
- **차폐된 뒤편(55 dB 이하)은 크게 바뀜**: 중앙 +0.8 ~ +2.6 dB, 높은 건물 뒤 그림자 +2 ~ +7 dB. 지금 SORI 는 이런 곳을 낮게 계산하고 있을 가능성이 큼(서울 고층 지역일수록).
- A 는 북서쪽 저층 밀집(붙은 건물 줄) 지역에서 크다 — 측면 경로가 옆 건물을 그대로 지나가기 때문이라 과대 추정으로 봄. B 는 막히면 경로를 통째로 버려 작다. **C 가 물리적으로 가장 그럴듯**(붙은 건물 줄은 줄 끝까지 돌아감).
- 표본: 높고 좁은 건물 뒤 묶음은 격자 범위(480 × 520 m) 안에 높이 20 m 이상 건물이 19동뿐이라 7점. 전농사거리 전체(2,911동) 중 30 m 이상 122동은 대부분 격자 밖.
- 계산 시간: 시제품(Python)에서 측면 회절이 직접음 계산의 약 10배(변형 C 는 더). numba 로 옮겼을 때 전체 계산(반사 3차 포함, 기존 1,342 s)에 얼마나 더해지는지는 구현 뒤에 잼.

## 한계

- 직접음 경로에만(반사 경로의 측면 회절 없음), 500 Hz 단일 대역, 격자 4 m 만, 벽면 수음점 없음.
- ISO 9613-2:2024 의 합치는 규칙(7.4.4)과 TR 17534-3 본문은 원문을 보지 못해 1996판 식과 목차 해석으로 함.
- 도로 음원 조각에 적용 — CNOSSOS 는 실제 점음원에만 허용(표준 밖 적용).
