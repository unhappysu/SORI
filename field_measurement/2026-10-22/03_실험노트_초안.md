## 기록 3 — 노면·속도·교차로·수음점 조건 반영 재계산 (2026-10-23 오후)

| 항목 | 내용 |
|---|---|
| 목적 | 모델 입력 가정을 바꿔 측정값과 다시 비교: 노면 AC11, 사가정로 속도 30/40/50 km/h, 지점2 수음점을 야장 건물 거리 1.13 m로, 신호교차로 보정 반영 |
| 코드 버전 | `bf31537` (기준 `9f710f4` + `model_compare.py` 재구성, `analyze.py`·`run_all.sh` 수정). noisemap 소스는 수정하지 않음 |
| 입력자료 | 기록 1·2와 같음 |
| 수행 내용 | ① 설정 `surface_map`으로 '아스팔트' → AC11 ② {R1, R2, R3, AVG} × {30, 40, 50 km/h} 12개 시나리오 ③ 지점2를 수치지도 건물선에서 1.13 m 앞에 배치(도로끝선 기준 위치 P2c도 계산) ④ build 뒤 sources.csv 의 D_K 를 가장 가까운 신호교차로 기준으로 다시 매기고 LW′ 를 같은 차이만큼 고친 뒤 run(코드 수정 없이 RLS-19 식 (5)와 같은 결과). 이후 noisemap 옵션 `dk_rule: nearest_signal`(커밋 `216882d`)로 대체(기록 4) ⑤ 차종 민감도, AVG_v50 소음지도 |
| 결과 | 3회 평균 모델 − 측정: 지점1 +5.6 / +6.6 / +8.2, 지점2 +5.7 / +6.8 / +8.4 dB(30 / 40 / 50 km/h). 이전(+9.7 / +10.6)보다 노면 −2.2, 신호교차로 +0.5~0.7, 지점2 위치 −0.4 dB. 지점 간 차이는 측정 +0.5, 모델 +0.7 dB |
| 오류·원인 | ① noisemap 기본 교차점 판정은 가장 가까운 교차점(전농로14길 접속부, other)을 써서 신호교차로 보정이 빠짐 → 외부에서 D_K 재계산 ② 지점2는 야장의 도로끝선 3.321 m와 건물 1.13 m를 수치지도에서 동시에 만족할 수 없음(수치지도 간격 6.25 m, 현장 4.45 m) ③ 30 km/h·AC11에서도 약 5.7 dB가 남음 |
| 결론 | 노면·속도 가정이 차이의 절반 가까이를 설명한다. 남는 5 dB 안팎은 차종 분류, RLS-19 방출식의 보수성, 정지 차량, 차폐 등으로 추정한다. 측정 자료만으로는 더 나눌 수 없다 |
| 다음 계획 | 기록 2의 다음 계획과 같음. 추가로 지점2 현장의 보도 폭과 건물선을 실측 |
