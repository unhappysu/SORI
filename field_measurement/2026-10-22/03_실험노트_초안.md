## 기록 2 — 이벤트 대조, 모델 비교, 소음지도 (2026-10-23 오후)

| 항목 | 내용 |
|---|---|
| 목적 | ① 상행·하행을 지도 기준으로 확정 ② 지점1 오토바이 기록을 실제 피크와 대조 ③ 규정 속도로 모델(noisemap)에 측정 교통량을 넣어 측정값과 비교 ④ 같은 조건으로 소음지도 작성 |
| 코드 버전 | 커밋 전. 기준 `3314afb` + `scripts/model_compare.py`, `scripts/wav_check.py`, `scripts/run_all.sh` 추가, `analyze.py`·`nl62.py` 수정. noisemap 소스는 수정하지 않음(`git diff noisemap/` 비어 있음). **커밋하면 해시를 적을 것** |
| 입력자료 | 기록 1과 같음 + 전농사거리 수치지도(baseline 과 같은 폴더), OpenStreetMap(주소점·maxspeed), WAV 녹음 |
| 수행 내용 | ① 도로명주소 번지(홀수 북측·짝수 남측)로 지점1 = 북측 = 상행, 지점2 = 남측 = 하행 확정 ② 야장 시각 ±60 s 안 가장 가까운 돌출 피크로 오토바이 구간 재설정 ③ 수치지도 보도 경계 + 실측 도로끝선 거리로 수음점 좌표 산정(지점1 뒤 건물 거리 1.01 m, 야장 1.001 m와 일치) ④ 사가정로 50 km/h(OSM maxspeed=50, 안전속도 5030), 화물차 = Lkw1, 방향 비율 실측으로 회차별·평균 모델 계산 ⑤ 직접음 손계산으로 모델 검산 ⑥ 속도·노면·차종 민감도 ⑦ 평균 교통량으로 격자·파사드 소음지도 ⑧ WAV 스펙트로그램으로 사이렌·경적 후보 확인, 사이렌으로 시계 차이 정밀 추정 |
| 결과 | **모델 LrT가 측정 LAeq보다 +8.8~+11.0 dB 높음**(평균 교통량: 지점1 78.3 vs 68.6, 지점2 79.7 vs 69.1). 모델 직접음은 손계산과 0.2 dB 이내로 일치. 30 km/h + AC11 노면 + 화물차 절반 Pkw로 다시 계산하면 +4.0 / +4.5 dB. 사이렌(16:31:40–16:32:10) 녹음으로 확인, 시계 차이 1.59 s(지점2가 늦음). 경적 후보는 순음성으로 2개 선별(16:43:15, 16:45:24) |
| 오류·원인 | ① 지점1 1회 오토바이 기록 시각(16:21:00)에 피크가 없고 32 s 뒤에 있음 → 기록 시각 오차로 판단, 피크 기준으로 제외 ② 모델·측정 10 dB 차이: 계산 오류는 아님(검산). 원인 후보는 규정 속도와 실제 주행속도(신호 접근부) 차이, 노면 기본 매핑(ref = 주입 아스팔트), 화물차 분류 기준 차이(2.8 t / 3.5 t), RLS-19 방출식의 보수성 ③ noisemap이 측정점 근처 음원에 사가정로 4→6차로 객체 접점(자동 판정 other, 서쪽 20~30 m)을 가장 가까운 교차점으로 잡아 신호 교차로 보정이 0 dB(소프트웨어 동작, 수정하지 않음) ④ 지점2 뒤 건물 거리가 수치지도 2.93 m, 야장 판독 1.13 m로 1.8 m 차이(미확인) ⑤ 화물차 계수에 이륜차가 포함됨(사용자 확인). 야장 양식(이륜차 = 승용차)과 다르게 셌고 이륜차 대수는 따로 없음 → 모델은 전부 Lkw1. RLS-19대로 이륜차를 Lkw2로 보면 모델이 0~+1.6 dB 더 높아짐 |
| 결론 | 측정 교통량과 규정 속도를 그대로 넣은 RLS-19 모델은 이 지점에서 약 10 dB 과대 예측한다. 그럴듯한 낮은 쪽 가정을 모두 써도 4 dB가 남는다. 소음지도의 절대 레벨은 이 점을 감안해 읽어야 한다 |
| 다음 계획 | ① 다음 측정 때 스피드건 등으로 주행속도 실측 ② 노면 종류 확인(포장 이력) ③ 화물차를 RLS-19 기준(3.5 t)으로 다시 분류해 계수 ④ 지점2 수음점 위치(건물 거리) 현장 확인 ⑤ noisemap 교차점 판정(가장 가까운 교차점 vs 신호 교차로) 검토 — 코드 변경은 별도 작업으로 ⑥ 다른 시간대 측정으로 비교 표본 확대 ⑦ 이륜차를 화물차와 따로 계수(RLS-19 Lkw2 대응) |
