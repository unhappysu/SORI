# 전농사거리 예제 (수치지도 별도)

> ※ 본 예제 자료는 Claude(Anthropic의 AI)를 활용하여 작성하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

서울 동대문구 전농사거리(사가정로·전농로·답십리로·서울시립대로) 소음지도 계산 설정입니다. 설정·교통량·측정점은 들어 있고, **수치지도는 들어 있지 않습니다**(국토지리정보원 자료로, 재배포 조건을 확인하지 못해 넣지 않음). 아래대로 받아 넣으면 바로 계산됩니다.

## 1. 수치지도 받기

1. 국토정보플랫폼(https://map.ngii.go.kr) → 공간정보 → 수치지도 → **수치지형도 v2.0**(1:1,000, SHP)
2. 도엽 9장: **377051731, 377051732, 377051733, 377051741, 377051742, 377051743, 377051751, 377051752, 377051753** (2025년 판으로 계산함)
3. 받은 zip 파일을 이 폴더의 `data/map/` 에 넣습니다. 압축을 풀어 넣어도 되고, zip 그대로 넣으면 SORI 앱의 **파일 ▸ 전농사거리 불러오기** 가 압축을 풀어 줍니다(하위 폴더도 자동으로 찾음).

## 2. 계산

- SORI 앱: **파일 ▸ 전농사거리 불러오기** → **▶ 계산 실행** (반사 3차 기본값, Apple Silicon 맥북 약 21분)
- 명령행: 이 폴더에서 `python -m sori all -c config.yaml`

## 3. 들어 있는 자료

| 파일 | 내용 |
|---|---|
| `config.yaml` | 계산 설정 — 입력 조건은 「전농사거리 소음현황조사 결과보고서」 6.8절(사가정로 50 km/h)과 같고, 반사는 SORI 기본값(3차). 보고서 조건(1·2차) 재현 줄은 주석으로 들어 있음 |
| `traffic.csv` | 계산에 쓰는 교통량(= `traffic/A_현장계수_50kmh.csv`) |
| `traffic/A_현장계수_50kmh.csv` | 사가정로: 2026-10-22 현장 계수(16시대 양방향 M_day 2,540 대/h, 화물차 25.83 %, 방향비 56.5:43.5), 50 km/h, 야간은 가정. 나머지 3개 노선: 가정 DTV × 서울 주·야 계수 |
| `traffic/B_현장계수_사가정로30kmh.csv` | A 와 같고 사가정로만 30 km/h |
| `traffic/C_가정값_기준선.csv` | 4개 노선 모두 가정 DTV(45,000 / 45,000 / 35,000 / 30,000 대/일) |
| `traffic/D_산정근거문서.csv` | 서울 조사지점 자료로 추정한 DTV·주야 계수(가정) |
| `points.csv` | 2026-10-22 현장 측정점(P1·P2·P2c) |

다른 교통량으로 계산하려면 원하는 파일을 `traffic.csv` 로 복사하거나 `config.yaml` 의 `input.traffic.path` 를 바꿉니다.
