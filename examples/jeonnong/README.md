# 전농사거리 예제 (계산 결과 포함, 수치지도·DEM 별도)

> ※ 본 예제 자료는 Claude(Anthropic의 AI)를 활용하여 작성하였음. 계산 결과의 검토·검증 책임은 사용자에게 있음.

서울 동대문구 전농사거리(사가정로·전농로·답십리로·서울시립대로) 소음지도 예제입니다. **계산 결과 두 가지가 들어 있어 수치지도 없이 바로 볼 수 있습니다.** SORI 앱을 처음 실행하면 기본값 계산 결과가 열립니다.

| 결과 | 설정 파일 | 결과 폴더 | 앱 메뉴 |
|---|---|---|---|
| 기본값 계산 (ISO 9613-2 전파, 반사 3차, 측면 회절) | `config.yaml` | `output/` | 파일 ▸ 전농사거리 불러오기(기본값 계산 결과) |
| SoundPLAN 비교 조건 (RLS-19, SoundPLAN_계산조건_정리 기준) | `config_soundplan.yaml` | `output_soundplan/` | 파일 ▸ 전농사거리 불러오기(SoundPLAN 비교 조건 결과) |

두 결과는 SORI v0.9, 커밋 `ac0e38b`(2026-11-20)의 계산 코드로 만든 것입니다. 계산 조건·환경은 각 결과 폴더의 `run_info.json` 에 있습니다. 앱은 이 예제를 `문서/SORI/전농사거리` 에 복사해 엽니다. 이미 복사된 폴더에서는 없는 파일·폴더만 채우므로, 고친 설정이나 다시 계산한 결과를 덮어쓰지 않습니다.

## 다시 계산하려면

수치지도와 DEM은 국토지리정보원 자료이고 재배포 조건을 확인하지 못해 넣지 않았습니다. 받아서 넣으면 다시 계산할 수 있습니다.

1. **수치지도** (두 설정 모두 필요): 국토정보플랫폼(https://map.ngii.go.kr) → 공간정보 → 수치지도 → **수치지형도 v2.0**(1:1,000, SHP), 도엽 9장 **377051731, 377051732, 377051733, 377051741, 377051742, 377051743, 377051751, 377051752, 377051753** (2025년 판으로 계산함). 받은 zip 을 `data/map/` 에 넣습니다. zip 그대로 넣으면 앱의 전농사거리 불러오기가 압축을 풀어 줍니다.
2. **DEM** (`config.yaml` 만 필요): 국토지리정보원 공개 DEM 도엽 37705(2025, img). `data/dem/전농사거리_(B080)공개DEM_37705_img_2025.zip` 이름으로 넣습니다. `config_soundplan.yaml` 은 DEM 을 쓰지 않습니다.
3. 계산: 앱에서 설정을 연 뒤 **▶ 계산 실행**, 또는 명령행에서 이 폴더 기준 `python -m sori all -c config.yaml`. 다시 계산하면 들어 있던 결과를 덮어씁니다.

## 들어 있는 자료

| 파일 | 내용 |
|---|---|
| `config.yaml` | 기본값 계산 설정 (03_전농사거리_SORI계산/config.yaml 과 같음) |
| `config_soundplan.yaml` | SoundPLAN 비교 조건 설정 (03_전농사거리_SORI계산/config_soundplan.yaml 과 같음) |
| `traffic.csv` | 기본값 계산 교통량 |
| `traffic_soundplan_1119.csv` | SoundPLAN 입력과 같은 교통량(방향별 화물차 비율 포함) |
| `roads_override.csv`, `roads_override_3_2.csv` | 도로별 확인값(차로 수 등). `_3_2` 는 사가정로 서행 3·동행 2 차로 |
| `points.csv` | 2026-10-22 현장 측정점(P1·P2·P2c) |
| `points_soundplan.csv` | SoundPLAN 수음점 M1·M2 와 현장 측정점 P1·P2 |
| `traffic/` | 교통량 대안(A 현장계수 50 km/h, B 사가정로 30 km/h, C 가정값 기준선, D 산정근거문서) |
| `output/`, `output_soundplan/` | 위 두 설정의 계산 결과 |
